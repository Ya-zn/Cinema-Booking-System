# Mini Cinema Booking System

A full-stack cinema booking project built to practice real-world backend architecture and booking business logic.

## Features

- Movies, halls, showtimes, and seats
- Showtime-specific seat availability
- Temporary seat holds with expiration
- Booking states: pending, confirmed, cancelled, expired
- Transaction-based booking operations
- REST API with Django REST Framework

## Tech Stack

- React
- JavaScript
- Python
- Django
- Django REST Framework
- SQLite

## Project Status

Currently in development.

## Learning Goals

This project focuses on:

- REST API design
- Database relationships
- Business rules
- Service layer architecture
- Transactions
- Booking concurrency concepts
